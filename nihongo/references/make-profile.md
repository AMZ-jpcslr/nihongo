# 書き方メモを作る

ユーザーが自分の書いた文を貼って「私の書き方を覚えて」「この感じで書いて」と頼んだ時に読む。貼られた文から、自分の名前で出す文に使う「書き方メモ」を作る。

メモは2段に分ける。上の段は「書く時の考え方」で、この人が何を先に言い、相手とどう距離を取るかを書く。場面をまたいで使う。下の段は場面ごとの欄で、一人称や言葉の例を書く。見える特徴を写すより、どう考えて書く人かを先に読む。言葉や記号だけを写すと、考え方の合わない場面でもそのまま出て、モノマネになる。

## 作り方

1. 貼られた文を、場面ごとに分ける（友達へのLINE、家族、先生・目上へのメール、仕事、SNSの告知・投稿など）。場面は、ユーザーが添えた言葉（「これは告知」）を一番に使い、無ければ宛名・敬語の高さ・出す場所から決める。決めた場面は欄の見出しで見えるので、聞かずに分けてよい。README・仕様書・設計書のような技術文書は型と用語の決まりが強いので、貼られても材料にしない（ユーザーが頼んだ時だけ使う）。
2. 上の段「書く時の考え方」に、次の点を拾う。文に出ていない点は書かない。
   - 先に言うこと（用件から入る、お礼から入る、結論を先に言う）
   - 相手との距離の取り方（すぐ本題に入る、相手の都合を先に聞く）
   - 気持ちの出し方（言葉で言う、記号で出す、あまり出さない）
   - お願いと断りの仕方（理由を1つ添える、代わりの案を出す、短く言い切る）
   - 長さ（1通の長さ、どこで改行するか）
   - 避けること（長い前置き、大げさなお礼）
3. 考え方は、2通以上で同じ選び方が見えた時だけ書く。どの文のどこから読んだかを言える物に限る。場面が違う2通でもよい。1通だけで見えた選び方は書かない。
4. 性格、年齢、性別、仕事、人間関係は推測しない。考え方は「どう書くか」で書き、「どんな人か」にしない（「相手の都合を先に聞く」は書いてよいが、「気づかいができる人」は書かない）。
5. 下の段は、場面ごとの欄にする。材料のある場面の欄だけ作り、同じ人でも場面で書き方は違うので、混ぜて1つにまとめない。拾うのは次の3つだけ。
   - 一人称（僕、私、自分、無し）
   - 文末が、です・ますか常体か
   - 言葉と記号の例（語尾、よく使う言葉、言い換えない言葉、記号と絵文字、書き出しと締め）
6. 一人称と、です・ますか常体かは、1通でも書く。この2つは1通でも読み取れるし、目上や店に宛てた文は1通しか無いことが多い。言葉と記号の例は、2通以上に出た時だけ書く。「〜っす」「〜わ」のような語尾と、定型の挨拶（「何卒よろしくお願い申し上げます」など）も同じ。1通だけの言葉を書くと、たまたま出た記号や言葉を毎回まねてしまう。目上への定型は場面の判断で入るので、メモには要らない。ユーザーが「これはいつも使う」と言った物は1通でも書く。
7. 言葉と記号の例には、どんな時に出るかを添える（「👍は了解の返事の時」「！は誘う文の時」）。回数ではなく、文の種類や気持ち、文の中の位置と結び付ける。結び付けられない物は書かない。
8. 言葉の例は「」で囲み、説明の文に溶かさない（「お疲れさまです」で始める）。溶かすと、書く時にそのまま文に入ってしまう。
9. 貼られた文の中身（人名、出来事、予定、場所、数字）は、メモに写さない。言葉の例は、中身を含まない言葉だけを使う。
10. 考え方は、欄の無い場面でも本人名義の文なら使う。言葉と記号の例は、貼られた文が無い場面には広げない。欄を作らないことで、その場面には使わないと分かるようにする。
11. 3通より少ない時は、そのまま作り、元にした通数をメモに書く。もっと貼ると精度が上がる、と1文だけ添える。

## 形

メモは次の形にする。設定にそのまま貼れるよう、考え方の段は300字くらい、場面の欄は1つ150字くらいまでにする。材料の無い行は消す。材料の無い場面の欄は作らない。

```
## 私の書き方（nihongo）
自分の名前で出す文に使う。技術文書と、AIとしての返事には使わない。敬語の高さは相手と場面で先に決め、メモはその中で使う（目上・お店・お知らせでは崩さない）。「書く時の考え方」は場面をまたいで使う。場面の欄は今の場面の欄だけを使い、欄が無い時と迷う時は使わない。言葉と記号の例は必ず入れる物ではなく、考え方に合う時だけ控えめに使う例。口ぐせのために、依頼に無い気持ちや中身を足さない。「〇〇の書き方で」と言われたらその欄を、「メモなしで」と言われたらメモを使わない。

### 書く時の考え方（〇通から）
- 先に言うこと：
- 相手との距離：
- 気持ちの出し方：
- お願いと断り：
- 長さ：
- 避けること：

### 友達へのLINE（〇通から）
- 一人称：
- 文末：
- 言葉と記号の例：

### 先生へのメール（1通から）
- 一人称：私
- 文末：です・ます
```

1通しか無い場面の欄は、一人称と文末の2行だけになる。

## 置き場所

メモはスキルのフォルダには置かない（スキルを更新すると消えるため）。ユーザーの設定に置く。

- Claude Code：`~/.claude/CLAUDE.md`（プロジェクトだけなら、プロジェクトの `CLAUDE.md`）
- Codex・Muse：`AGENTS.md`
- Claude・ChatGPTのアプリ：設定にある、AIへの指示や好みを書く欄

ファイルを書ける環境では、書き足してよいかを1回聞き、OKなら末尾に書き足す。すでに「## 私の書き方（nihongo）」があれば、考え方の段は新しい材料と合わせて書き直し、新しい場面の欄は足し、同じ場面の欄は差し替える。書けない環境では、メモと置き場所を1行で返す。

## 育てる

自分の名前で出す文の下書きを、ユーザーが「僕はこう書かない」と直した時は、直した点をメモの1行にして見せ、足してよいかを聞く。言葉の直しは場面の欄に足し（使わない言葉：「〜させていただきます」）、そこから読める選び方は考え方の1行に言い直して足す（「了解しました」→「了解です」と直されたら、言葉の例に「了解です」、考え方に「了解やお礼は短く言い切る」）。言い直した考え方は推測を含むので、足す前に必ず見せる。直した例は、貼った文より確かな材料として扱う。
