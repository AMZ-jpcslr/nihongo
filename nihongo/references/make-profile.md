# 書き方メモを作る

ユーザーが自分の書いた文を貼って「私の書き方を覚えて」「この感じで書いて」と頼んだ時に読む。貼られた文から、自分の名前で出す文に使う「書き方メモ」を作る。

## 作り方

1. 貼られた文を、場面ごとに分ける（友達へのLINE、家族、先生・目上へのメール、仕事、SNSの告知・投稿など）。同じ人でも場面で書き方は違うので、混ぜて1つにまとめない。メモは場面ごとの欄に分け、材料のある場面の欄だけ作る。場面は、ユーザーが添えた言葉（「これは告知」）を一番に使い、無ければ宛名・敬語の高さ・出す場所から決める。決めた場面は欄の見出しで見えるので、聞かずに分けてよい。README・仕様書・設計書のような技術文書は型と用語の決まりが強いので、貼られても欄を作らない（ユーザーが頼んだ時だけ作る）。
2. 次の点だけを拾う。文に出ていない点は書かない。
   - 一人称（僕、私、自分、無し）
   - 文末（です・ます、だ・である、〜よね、〜かも、方言）
   - 記号と絵文字（！の多さ、「w」、使う絵文字、顔文字）
   - 硬さ（目上への敬語の高さ、友達への崩し方）
   - 長さと改行（1〜2文で改行、1通の長さ）
   - よく使う言葉（正直、まじで、とりあえず）と、言い換えない言葉（確認、PR）
   - 書き出しと締め（お疲れさまです、よろしく、無し）
3. 特徴は、どんな時に出るかで書く。回数ではなく、文の種類や気持ち、文の中の位置と結び付ける（「👍は了解の返事の時」「！は誘う文の時」「🎉は1行目の後だけ」）。どの時にも出る物は「いつも」と書く。結び付けられない特徴は、通数を添えて「時々」と書く。
4. 一人称・文末・硬さの3つは、1通でも書く。この3つは1通でも読み取れるし、目上や店に宛てた文は1通しか無いことが多い。記号と絵文字、長さと改行、よく使う言葉、書き出しと締めは、2通以上に出た時だけ書く。1通だけのクセを書くと、たまたま出た記号や言葉を毎回まねてしまう。ユーザーが「これはいつも使う」と言った物は1通でも書く。
5. 言葉の例は「」で囲み、説明の文に溶かさない（「お疲れさまです」で始める）。溶かすと、書く時にそのまま文に入ってしまう。
6. 貼られた文の中身（人名、出来事、予定、場所、数字）は、メモに写さない。口ぐせは、中身を含まない言葉だけを例に使う。
7. 性格、年齢、性別、仕事、人間関係は推測しない。メモは書き方だけにする。
8. 貼られた文が無い場面には、メモを広げない。欄を作らないことで、その場面には使わないと分かるようにする。
9. 3通より少ない時は、そのまま作り、元にした通数をメモに書く。もっと貼ると精度が上がる、と1文だけ添える。

## 形

メモは次の形で、設定にそのまま貼れる長さ（1つの欄で200字くらいまで）にする。材料の無い行は消す。材料の無い場面の欄は作らない。

```
## 私の書き方（nihongo）
自分の名前で出す文を書く時に、今の場面の欄だけを使う。敬語の高さは相手と場面で先に決め、メモはその中で使う（目上・お店・お知らせでは崩さない）。どの欄に当たるか迷ったら使わない。クセは書いてある「どんな時」に当てはまる文にだけ使い、全部の文には入れない。「〇〇の書き方で」と言われたらその欄を、「メモなしで」と言われたら使わない。欄の無い場面と、AIとしての返事には使わない。口ぐせのために、依頼に無い気持ちや中身を足さない。

### 友達へのLINE（〇通から）
- 一人称：
- 文末：
- 硬さ：
- 記号・絵文字：
- 長さ・改行：
- よく使う言葉：

### SNSの告知・投稿（〇通から）
- （同じ項目）

### 先生へのメール（1通から）
- 一人称：
- 文末：
- 硬さ：
```

1通しか無い場面の欄は、一人称・文末・硬さの3行だけになる。

## 置き場所

メモはスキルのフォルダには置かない（スキルを更新すると消えるため）。ユーザーの設定に置く。

- Claude Code：`~/.claude/CLAUDE.md`（プロジェクトだけなら、プロジェクトの `CLAUDE.md`）
- Codex・Muse：`AGENTS.md`
- Claude・ChatGPTのアプリ：設定にある、AIへの指示や好みを書く欄

ファイルを書ける環境では、書き足してよいかを1回聞き、OKなら末尾に書き足す。すでに「## 私の書き方（nihongo）」があれば、新しい場面の欄は足し、同じ場面の欄は差し替える。書けない環境では、メモと置き場所を1行で返す。

## 育てる

自分の名前で出す文の下書きを、ユーザーが「僕はこう書かない」と直した時は、直した点をメモの1行にして見せ、足してよいかを聞く（例：使わない言葉：「〜させていただきます」、直した例：「了解しました」→「了解です」）。直した例は、貼った文より確かな材料として扱う。
