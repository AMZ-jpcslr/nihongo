# 書き方メモを作る

ユーザーが自分の書いた文を貼って「私の書き方を覚えて」「この感じで書いて」と頼んだ時に読む。貼られた文から、自分の名前で出す文に使う「書き方メモ」を作る。

メモは2段に分ける。上の段は「書く時の考え方」で、この人が何を先に言い、相手とどう距離を取るかを書く。場面をまたいで使う。下の段は場面ごとの欄で、一人称・文末・長さ・言葉の例を書く。2段の前に、本人が自分で言ったことと直したことを書く「こだわり」の欄を置く。見える特徴を写すより、どう考えて書く人かを先に読む。言葉や記号だけを写すと、考え方の合わない場面でもそのまま出て、モノマネになる。

## 作り方

1. 貼られた文を、場面ごとに分ける（友達へのLINE、家族、先生・目上へのメール、仕事、SNSの告知・投稿など）。場面は、ユーザーが添えた言葉（「これは告知」）を一番に使い、無ければ宛名・敬語の高さ・出す場所から決める。決めた場面は欄の見出しで見えるので、聞かずに分けてよい。README・仕様書・設計書のような技術文書は型と用語の決まりが強いので、貼られても材料にしない（ユーザーが頼んだ時だけ使う）。
2. 文ごとに、何を選んだかを読む。用件を先に言ったか、お礼やお詫びを入れたか、気持ちを言葉で言ったか記号で出したか、言い切ったかぼかしたか、断る時に理由を先に言ったか、相手をどう呼び、敬語をどの段にしたか。
3. 2通以上で同じ選び方が見えたら、考え方の1行にする（項目は下の「考え方の項目」）。どの場面の何通から読んだかを添える。場面が違う2通でもよい。1通だけで見えた選び方は書かない。
4. 場面どうしの差を使う。友達と目上で何が変わり、何が変わらないかは、相手との距離の取り方の一番の材料になる。
5. 場面ごとの欄に、一人称、文末、長さと改行、言葉と記号の例を書く。材料のある場面の欄だけ作り、同じ人でも場面で書き方は違うので、混ぜて1つにまとめない。
   - 一人称と、です・ますか常体かは、1通でも書く。この2つは1通でも読み取れるし、目上や店に宛てた文は1通しか無いことが多い。
   - 長さと改行、言葉と記号の例（語尾、よく使う言葉、言い換えない言葉、記号と絵文字、書き出しと締め）は、2通以上に出た時だけ、どんな時に出るかと一緒に書く（「👍は了解の返事の時」「！は誘う文の時」）。「〜っす」「〜わ」のような語尾と、定型の挨拶（「何卒よろしくお願い申し上げます」など）も同じ。目上への定型は場面の判断で入るので、メモには要らない。ユーザーが「これはいつも使う」と言った物は1通でも書く。
   - 言葉の例は「」で囲み、説明の文に溶かさない（「お疲れさまです」で始める）。溶かすと、書く時にそのまま文に入ってしまう。
6. 書いた後に点検する。メモの各行を、貼った文に無い場面（目上へのお詫び、お知らせなど）に当ててみて、失礼・作り話・モノマネになる行は消すか、条件を付ける（「友達へのLINEの時だけ」）。下の「書いてはいけない物」に当たる行も消す。
7. メモを見せ、違う所があれば直して、と1文だけ添える。3通より少ない時は元にした通数を書き、もっと貼ると精度が上がる、と1文だけ添える。

考え方は、欄の無い場面でも本人名義の文なら使う。言葉と記号の例は、貼られた文が無い場面には広げない。欄を作らないことで、その場面には使わないと分かるようにする。

## 考え方の項目

場面をまたいで当てはまり、文から読める物だけにする。

- 先に言うこと（用件、お礼、気持ち）
- 相手との距離の取り方（どこまで詰めるか、目上との線の引き方）
- 気持ちの出し方（言葉で言う、記号で出す、控えめ）
- 言い切り方（言い切る、ぼかす、確かさで分ける）
- お願いと断りの仕方（理由を先に言う、短くまっすぐ言う）
- 避けること（大げさな言葉、へりくだりすぎ など）

長さと改行は場面で変わるので、場面ごとの欄に置く。

## こだわりの欄

本人が自分で言ったことと、本人が直したことは、「こだわり」の欄に書く（「〜させていただきます」は使わない、前置きは書かない、短く書きたい）。貼った文から読んだだけの物は入れない。

- 1回言われただけ、1通直されただけでも書く。本人の言葉なので、2通以上の決まりは当てない。
- 場面をまたいで使い、メモの中では一番優先する。考え方や言葉の例とぶつかったら、こだわりに合わせる。
- ただし、相手と場面で決めた硬さと、作り話をしないことは超えない（「敬語は使わない」とあっても、先生へのメールでは崩さない）。
- 性格は推測しないが、本人が自分について言ったこと（「短く書きたい」）は、この欄に書いてよい。

## 書いてはいけない物

- 貼った文の中身（人名、出来事、予定、場所、数字）
- 人物像（性格、価値観、年齢、性別、仕事、人間関係）。文から確かめられず、推測すると作り話になる。考え方は「どう書くか」で書き、「どんな人か」にしない。本人が自分で言った物は「こだわり」に書く
- 1通にしか出ない語尾・口ぐせ・定型
- 回数だけで書いたクセ（「！を毎文に付ける」）
- 目上に敬語を下げる指示（店長の欄の「〜っす」）

悪いメモと、直したメモの例（どちらも架空の人で、合成）：

```
### 書く時の考え方
- 明るくて気配りができる人
- 毎文に「！」を付ける

### バイト先の店長へのLINE（1通から）
- 文末：「〜っす」
- 言葉の例：「来週土曜のシフト」
```

人物像を書き、回数だけでクセを書き、1通の語尾で目上に崩し、貼った文の中身を写している。

```
### 書く時の考え方（LINE 3通・メール2通から）
- 先に言うこと：用件を1文目に書き、お礼は最後に短く言う
- 気持ちの出し方：友達には「！」で出し、目上には言葉で言う
- お願いと断り：断る時は理由を1つ先に言い、代わりの日を出す

### バイト先の店長へのLINE（1通から）
- 一人称：自分
- 文末：です・ます
```

## 形

メモは次の形にする。設定にそのまま貼れるよう、考え方の段は300字くらい、場面の欄は1つ150字くらいまでにする。材料の無い行は消す。材料の無い場面の欄は作らない。

```
## 私の書き方（nihongo）
自分の名前で出す文に使う。技術文書と、AIとしての返事には使わない。敬語の高さは相手と場面で先に決め、メモはその中で使う（目上・お店・お知らせでは崩さない。絵文字はその欄にある時だけ使い、ほかの欄の絵文字や「っす」「w」は持ち込まない）。「こだわり」と「書く時の考え方」は場面をまたいで使い、こだわりをメモの中で一番優先する（硬さの判断と、作り話をしないことは超えない）。場面の欄は今の場面の欄だけを使い、欄が無い時と迷う時は使わない。言葉と記号の例は必ず入れる物ではなく、考え方に合う時だけ控えめに使う例。口ぐせのために、依頼に無い気持ちや中身を足さない。「〇〇の書き方で」と言われたらその欄を、「メモなしで」と言われたらメモを使わない。

### こだわり
- （本人が言ったこと、直したこと）

### 書く時の考え方（〇通から）
- 先に言うこと：
- 相手との距離：
- 気持ちの出し方：
- 言い切り方：
- お願いと断り：
- 避けること：

### 友達へのLINE（〇通から）
- 一人称：
- 文末：
- 長さ・改行：
- 言葉と記号の例：

### 先生へのメール（1通から）
- 一人称：私
- 文末：です・ます
```

1通しか無い場面の欄は、一人称と文末の2行だけになる。

## 置き場所

メモはスキルのフォルダには置かない（スキルを更新すると消えるため）。ユーザーの設定に置く。

- Claude Code：`~/.claude/CLAUDE.md`（プロジェクトだけなら、プロジェクトの `CLAUDE.md`）
- Codex・Muse：`AGENTS.md`
- Claude・ChatGPTのアプリ：設定にある、AIへの指示や好みを書く欄

ファイルを書ける環境では、書き足してよいかを1回聞き、OKなら末尾に書き足す。すでに「## 私の書き方（nihongo）」があれば、こだわりの欄は残したまま足し、考え方の段は新しい材料と合わせて書き直し、新しい場面の欄は足し、同じ場面の欄は差し替える。書けない環境では、メモと置き場所を1行で返す。

## 育てる

自分の名前で出す文の下書きを、ユーザーが「僕はこう書かない」と直した時や、「こう書きたい」と言った時は、それを「こだわり」の欄の1行にして見せ、足してよいかを聞く（「了解しました」→「了解です」と直されたら、「了解は「了解です」と短く言う」）。直した例は、貼った文より確かな材料として扱う。直しから考え方を読み取れそうでも、推測になるので、こだわりの欄には本人が直した形のまま書く。
